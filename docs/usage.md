# 使用说明

适用范围：Claude Desktop → Code → 本地项目。安装方式见仓库首页。

## 账号接续

打开“Claude 接续助手”，选择“切换账号并接续原会话”。从最近使用的本地会话中选择原会话，确认目标账号 A/B 标记。

助手会在原项目下记录会话位置和最近对话，再打开 Claude。让原任务停止后，通过 Claude 左下角的账号菜单退出登录，登录目标账号并核对实际邮箱。回到助手点击“已登录，继续”，工具调用：

```sh
claude --desktop --resume <原会话ID>
```

请确认桌面端的项目、账号和聊天记录，再继续发送任务。命令成功返回只表示恢复请求已经发出。

如果暂时不能登录，可以选择“稍后接续”。之后选择“恢复已记住的原会话”，指定同一本地项目目录。

## 没有恢复原会话时

在桌面 Code 中选择同一个本地项目/工作树目录，创建新会话，粘贴助手已复制的接续提示词。也可以通过菜单“接续工作：复制接续提示词”重新取得提示词。

目标会话读取最近对话节选、交接笔记和当前 Git 状态，重建工作进度。笔记没有填写时，先从最近对话中提取任务；仍不明确时再询问用户。

节选最多包含最近 40 条用户/助手文本，每条最多约 4000 字符，正文总长最多约 8 万字符。工具结果、图片和思考过程不在节选中。原始对话保留原样，可根据记录路径按需回查。

## 保存进度

原账号仍有用量时，选择“保存进度：复制整理提示词”，在原 Code 会话中粘贴并发送，让 Claude 更新 `NOTES.md`。确认目标、决定、已完成、验证结果和下一步实际写入后，语义进度才算保存。

已经达到限制时，仍可生成最近对话节选，也可以选择“打开交接笔记”手动补写。

## 本地数据

交接资料位于所选项目的 `.claude-handoff/`：

| 文件 | 用途 |
| --- | --- |
| `session.json` | 原会话 ID、目录、标题及原记录路径 |
| `CONVERSATION.md` | 最近用户/助手文本节选 |
| `NOTES.md` | 目标、进度、决定、验证结果与下一步 |
| `state.json` | 当前目录与 Git 状态快照 |
| `保存进度提示词.txt` | 让原会话整理进度 |
| `接续工作提示词.txt` | 让目标会话接续工作 |
| `tool.json` / `.gitignore` | 工具标记及本机资料忽略规则 |

重复运行会保留已有笔记。工具读取桌面本地会话元数据及对话文件，提取所需字段，不改写原始会话索引或账户归属。生成的对话节选包含原消息文字，默认留在本机。

同一目录里的业务文件、依赖、项目指令和本地设置继续使用。云端连接器、账号权限、终端进程、虚拟环境和浏览器状态需要按实际情况确认。

## 范围与清理

- 选择原会话实际使用的目录；使用 Git worktree 时应选择原工作树。
- 让修改代码的任务停止后再接续，避免两个会话同时写入同一工作树。
- 当前工具面向本地 Code；云端或服务器项目需要另行处理。
- 交接资料不是源代码备份，不能恢复已删除的未提交文件或工作树。
- 将应用移到废纸篓即可卸载入口；项目内的 `.claude-handoff/` 可在不再需要进度后自行删除。

官方入口说明：[Desktop — Coming from the CLI?](https://code.claude.com/docs/en/desktop#coming-from-the-cli)。
